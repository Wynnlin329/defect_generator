# 技術文件模板

## 文件目的
本文件用於整理某個技術主題、系統設計、模組行為、資料流、交接內容、版本變更或操作方式，作為工程、維運、交接或簡報整理的基礎文件。

本模板可搭配 `technical-documentation` skill 使用。
